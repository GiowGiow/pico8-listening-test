# PICO-8 Percept: web

Front end of the PICO-8 listening test, adapted from
[humanness-percept-web](https://github.com/HenriqueDSousa/humanness-percept-web).
Astro (SSR on Node) with React islands and Paraglide for Portuguese and English.

The API is served on the same origin under `/api` (the ingress routes it to the
server container), so the browser makes no cross-origin request and the page
carries a hash-based Content Security Policy generated by Astro. The study
question, the scale labels and the questionnaire come from `/api/study`, so the
page shows them exactly as the research package words them (in Portuguese, in
both locales).

## Pages

| Path | What |
|------|------|
| `/` | Presentation and e-mail form |
| `/register` | Six multiple-choice questions about the participant, before the test |
| `/instructions` | The three steps of the test |
| `/survey` | A scenario per screen: game picture and description, players A to D, a five-point scale each |
| `/thank-you` | End |

## Development

Needs Node 22.23.4+ (Astro 7) and the server running on port 5000; the dev
server proxies `/api` to it.

```bash
npm install
npm run dev
```

## Image

```bash
docker build -t pico8-percept-web .
docker run --read-only -p 4321:4321 pico8-percept-web
```

`PUBLIC_CONTACT_EMAIL` (build argument) adds a contact line to the footer.
